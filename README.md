# Edge C-Means Clustering

本リポジトリは，データ間の曖昧な関係性やクラスタ間の接続構造を分析するクラスタリング研究の一部を整理したものです．

> **注意**  
> 本リポジトリは，論文投稿前の公開用リポジトリとして整備しています．  
> そのため，提案手法の新規性に関わる定式化，目的関数，更新則，アルゴリズム，計算量削減の詳細，および実装コードは意図的に非公開としています．  
> 現時点では，研究の概要と一部の可視化結果のみを公開しています．

## 概要

本研究では，従来のクラスタリング手法では十分に表現しにくい，クラスタ間の曖昧な関係性や接続構造を扱う手法について検討しています．

特に，人工データを用いた可視化実験により，データ分布に沿ったネットワーク構造の形成や，パラメータ変化に伴う挙動の違いを確認しています．

ただし，本リポジトリでは，論文投稿前であることを考慮し，提案手法の核心部分は公開していません．

## 公開している内容

本リポジトリでは，以下の内容を公開しています．

- 研究概要
- 人工データに対する可視化結果
- クラスタ数やパラメータ変化に伴う代表的な挙動
- ノイズを含むデータに対する可視化結果
- 3次元人工データに対する可視化結果
- 公開しても新規性の喪失につながりにくい補足資料

## 非公開としている内容

## Results

results/graph/ には，公開可能な範囲で実験結果の可視化画像を配置しています．

主に以下の観点から結果を整理しています．

- 2次元人工データに対するネットワーク構造の可視化
- クラスタ数の違いによる構造変化
- パラメータの違いによる局所性・平滑性の変化
- ノイズを含むデータに対する構造抽出
- 3次元人工データに対する可視化

なお，図の解釈は研究内容の概要に留めており，提案手法の具体的な計算手順やアルゴリズムの詳細は含めていません．
