# research-ecm

データ間の曖昧な関係性を扱う新しいクラスタリング手法 **Edge C-Means (ECM)** の提案と特性評価。大阪公立大学 卒業研究のコードと論文を公開しています。

## 概要

クラスタリングは類似データを教師なしで分類する技術ですが、代表的な k-Means（Hard C-Means）法は各データを単一のクラスターに排他的に割り当てるため、クラスター間の接続関係を表現できません。

ECM 法は、各データを 1 つの「点」ではなく、異なる 2 つのクラスター中心を結ぶ **有向辺** へ帰属させることで、複数クラスターへの帰属（曖昧さ）とクラスター間の接続関係（トポロジー構造）を同時に扱う手法です。クラスタリングを **目的関数の最適化問題** として定式化している点が特徴で、ヒューリスティックな既存手法（SOM・GNG など）に比べて理論的基盤が明確です。

## 手法のポイント

- **辺への帰属**: 各データを最近傍・第2近傍のクラスター中心が張る有向辺へ割り当て、オーバーラップを表現
- **目的関数の最適化**: HCM 法を拡張した目的関数を定義し、更新則を導出
- **計算量削減**: 再配列不等式を用い、全辺の評価（O(C²)）を最近傍・第2近傍の選択（O(C)）へ削減
- **接続強度**: 各辺への帰属数からクラスター間の接続の強さを定量化し、閾値処理でノイズ由来の辺を除去
- **GNG との対応**: 提案法の更新則が GNG のノード更新則に対応することを示し、経験則的手法に理論的裏付けを付与

## 実験

人工データを用いて挙動と特性を評価しています。

- 2次元データ（二重円・三日月）でのネットワーク構造の可視化
- クラスター数 C の影響（C = 2〜256）
- 重みパラメータ α の影響（局所性と平滑性の制御）
- 接続強度の閾値処理によるノイズ除去
- 3次元データ（螺旋・2変量正規分布）への適用

## ディレクトリ構成

- `src/` — ECM 法の実装と数値実験のコード
- `data/` — 使用データの説明（生データは非同梱）
- `results/` — 実験出力の説明（生成物は非同梱）
- `docs/` — 論文・ノート類

## 実行方法

```bash
pip install -r requirements.txt

# 例: 人工データに ECM を適用して可視化
python src/run_ecm.py
```

（スクリプト名・引数は実際のコードに合わせて書き換えてください）
