# Edge C - Means Clustering

本リポジトリは，データ間の曖昧な関係性を分析するクラスタリング手法に関する研究成果の一部を整理したものです．

> **注意**  
> 本リポジトリは，論文投稿前の公開用リポジトリとして整備しています．  
> そのため，提案手法の詳細な定式化，アルゴリズム，更新式，実装コード，未公開論文・卒業論文の内容は意図的に非公開としています．

## 概要

本研究では，クラスタ間の関係性を考慮したクラスタリング手法について検討しています．

現時点では，本リポジトリでは以下の内容のみを公開しています．

- 実験結果の可視化
- 合成データに対する代表的な挙動
- 研究発表用の一部図表
- 公開しても問題のない補足資料

提案手法の具体的な目的関数，最適化手順，更新式，および実装コードは，論文投稿前のため公開していません．

## 公開内容

- `results/`  
  実験結果や可視化画像を格納しています．

- `docs/`  
  公開可能な補足資料のみを格納します．  
  未公開論文，卒業論文，詳細な手法説明は含みません．

- `src/`  
  現時点では公開用の説明のみを配置しています．  
  提案手法の実装コードは，論文投稿前のため公開していません．

## 非公開としている内容

以下の内容は，論文投稿前であるため本リポジトリには含めていません．

- 提案手法の詳細な定式化
- 目的関数や更新式の導出
- 提案アルゴリズムの実装コード
- 未公開の卒業論文・投稿論文
- 手法の核心部分が分かる実験notebook
- 再現に必要な詳細なパラメータ設定や内部処理

これらの内容は，論文投稿または採択後に，公開方針を検討したうえで追加する可能性があります．

## 現在の状態

本リポジトリは，研究内容の概要と一部の実験結果を公開するためのものです．  
現時点では，未公開研究の新規性を保護することを優先しています．
